# OLED Sniffer - эмулятор SSD1306/SH1106 на ESP32-C3

Устройство эмулирует OLED-дисплей по I²C, перехватывает всё, что мастер
(обычно STM32 / Arduino / ESP32) шлёт "своему" дисплею, восстанавливает
framebuffer 128×64 и отдаёт его через веб-интерфейс: живое превью,
покадровый захват в RAM с выгрузкой в PNG, галерея режимов рендера,
ZIP-архив, привязка к локальной Wi-Fi сети.

---

## Возможности

- **Эмуляция SSD1306** - адрес `0x3C` или `0x3D`, переключается в UI.
- **Эмуляция SH1106** - с компенсацией сдвига колонок −2, переключается
  кликом по бейджу драйвера.
- **19 режимов разбора framebuffer'а** - page / row / column-major,
  MSB/LSB-first, отражения по горизонтали и вертикали, инверсия.
  Полезно, если захватывается самодельный контроллер
  с неизвестным форматом кадра.
- **Живое превью экрана** - обновляется через `preview.bin` (1024 байта
  сырого framebuffer'а), клиент рисует его на `<canvas>` в выбранном
  режиме.
- **Пакетный захват** - по кнопке "Захват" кадры пишутся в RAM строго
  по интервалу, не тормозя превью. При заполнении RAM (или по кнопке
  "Стоп") все кадры сохраняются в PNG на LittleFS.
- **Автостоп** - при заполнении RAM захват останавливается и обработка
  запускается автоматически, как будто нажали "Стоп".
- **ZIP-выгрузка** всего содержимого LittleFS одним архивом.
- **Очистка** всех файлов (кроме настроек) одной кнопкой.
- **Своя Wi-Fi точка + опциональная привязка к домашней сети**
  одновременно (AP+STA). Если домашняя сеть отваливается больше чем
  на 10 секунд - встроенная AP включается обратно автоматически.

## Подключение

| ESP32-C3 | Куда |
|---|---|
| GPIO5 | SDA мастера |
| GPIO4 | SCL мастера |
| GND | GND мастера |

- Адрес по умолчанию: **0x3C**, переключается на **0x3D** кнопкой в UI.
- Шина: **100 кГц** (стандарт для SSD1306).
- **Подтяжки SDA/SCL к 3.3 В** обязательны (обычно 2.2–4.7 кОм).
- **Настоящий OLED надо снять с шины.** Иначе будет конфликт адресов,
  и эмулятор будет получать искажённые данные.

## Первый запуск

1. Прошей `OLED_Sniffer.ino` (Arduino IDE или PlatformIO).
2. При включении ESP32-C3 поднимает свою точку доступа:

   | Параметр | Значение |
   |---|---|
   | SSID | `OLED` |
   | Пароль | `oledsniffer` |
   | IP | `192.168.4.1` |

3. Открой `http://192.168.4.1/` или `http://oledsniffer.local/` (mDNS).

## Веб-интерфейс

Главная страница - `http://oledsniffer.local/`.

### Верхний блок

- **Wi-Fi** (раскрывающийся) - состояние AP/STA, поля SSID/пароль
  домашней сети, кнопки "Подключить / Переподключить / Забыть".
- **Бейджи параметров**:
  - `PNG` - сколько `frame_*.png` в LittleFS.
  - `Сохранено` - сколько PNG сохранено за текущую сессию.
  - `RAM` - сколько слотов RAM-буфера заполнено из общего числа.
  - `Heap` - свободная RAM.
  - `FS` - свободное место в LittleFS.
  - `I²C: 0x3C` - **кликабельно**, переключает адрес на `0x3D` и обратно.
  - `SSD1306` - **кликабельно**, переключает драйвер на `SH1106` и обратно.

### Управление

- **Статус** - "остановлен", "захват N/M", "рендер i/N". Цветная точка:
  серая (простой) / зелёная (захват) / оранжевая (обработка).
- **Интервал, мс** - с какой частотой писать кадры в RAM при захвате.
- **Захват** - старт. Кадры копятся в RAM, HTTP и превью не тормозят.
- **Стоп** - прекратить захват и сразу начать обработку.
  Если обработка уже идёт - прерывает её.

### Режим / экспорт

- **Режим рендера** - выбирается на странице `/renders` (клик по
  правильной миниатюре). На главной странице выводится текущий режим.
- **Скачать всё (ZIP)** - весь LittleFS (кроме настроек) в одном архиве.
- **Очистить всё** - удаляет все `.png` и `r_*.png`, сбрасывает
  нумерацию. Файлы настроек (`mode.txt`, `addr.txt`, `drv.txt`,
  `wifi.txt`) не трогает.

### Галерея

Сетка миниатюр сохранённых PNG. Новые кадры появляются по мере обработки. 
По клику открывается полноразмерная картинка, кнопка "PNG ↓" - скачивание.

## Дополнительные страницы

| URL | Что делает |
|---|---|
| `/` | главная |
| `/renders` | 19 вариантов рендера текущего framebuffer'а. Клик по карточке делает режим активным. Файлы `r_*.png` временные, к кадрам не относятся. |

| `/api/frames` | JSON со статистикой и списком PNG |

| `/api/wifi` | JSON со статусом AP/STA |

| `/wifi/reconnect` | переподключиться к сохранённой своей сети |
| `/wifi/forget` | удалить креды своей сети |

## Как пользоваться

### 1. Быстрый захват анимации

1. Открой главную, дождись превью (обычно сразу работает).
2. Установи интервал, например `500` мс.
3. Нажми **Захват**.
4. Дай мастеру отрисовать то, что нужно (например, 20 секунд игры).
5. Нажми **Стоп** (или дождись, когда RAM заполнится и обработка
   стартует сама).
6. В галерее появятся PNG'и.

RAM-буфер автоматически подбирается под свободный heap: обычно
80–120 слотов. Итоговое число видно в бейдже `RAM`.

### 2. Если картинка мусорная

1. Открой `/renders`.
2. Посмотри 19 миниатюр.
3. Кликни по той, что похожа на настоящий экран - она станет активной.
4. Все последующие кадры будут сохраняться уже в этом режиме.

### 3. Подключение к своей Wi-Fi сети

1. На главной разверни **WiFi**.
2. Введи SSID и пароль домашней сети, нажми **Подключить**.
3. Устройство останется доступно и по адресу `192.168.4.1`, и по новому
   IP от роутера. mDNS `oledsniffer.local` работает на обоих интерфейсах.
4. Кнопка **Забыть** удаляет креды; AP продолжает работать.

## Настройки, которые сохраняются

Все файлы лежат в LittleFS и переживают перезагрузку.

| Файл | Содержимое |
|---|---|
| `/mode.txt` | индекс активного режима рендера (0–18) |
| `/addr.txt` | I²C-адрес в hex: `3C` или `3D` |
| `/drv.txt` | драйвер: `0` = SSD1306, `1` = SH1106 |
| `/wifi.txt` | SSID и пароль домашней сети (2 строки) |

Сбрасываются только вручную (кнопка **Забыть** для Wi-Fi) или полной
очисткой Flash.

## Ограничения и нюансы

- **Это эмулятор SSD1306/SH1106, а не универсальный I²C-анализатор.**
  Он понимает типичный поток "control byte + команды/данные", который
  шлют Adafruit_SSD1306, u8g2, esp-idf-драйверы. Если мастер шлёт
  что-то своё (например, RGB565 или 16 бит/пиксель), нужен отдельный
  режим рендера или доработка кода.
- **RAM-буфер** живёт между сессиями. Он освобождается только при
  перезагрузке. Это сделано для того, чтобы не фрагментировать heap.
- **Превью быстрое, но не мгновенное.** Обычно 4-12 FPS в браузере -
  этого достаточно, чтобы видеть, что происходит на экране, но 60 FPS
  ждать не стоит.
- **AP+STA**: если домашняя сеть на канале 1–11 (типично), всё ок. Если
  на 12–14, соединение может рваться - редкость.
- **Нагрев.** Прошивка оптимизирована под минимальный нагрев: TX power
  2 dBm, CPU 80 MHz, modem sleep для STA. Устройство может нагреваться,
  но в пределах разумного.

## Лицензия и авторство

Стартовая реализация для SSD1306 128×64, не претендует на
универсальность. Используй как хочешь.
